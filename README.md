# NotasyCuadernos-App 📝💻

Aplicación web interactiva orientada a la productividad, organización personal y gestión ágil de apuntes y tareas en tiempo real.

### 🚀 Características del Proyecto:
* **Gestión Dinámica de Notas:** Lógica implementada para crear, visualizar y organizar apuntes de forma instantánea con una interfaz limpia.
* **Diseño Orientado a la Productividad (UX/UI):** Estética minimalista y moderna, pensada para evitar distracciones y priorizar el foco del usuario.
* **Control de Eventos:** Manipulación avanzada del DOM para garantizar una respuesta inmediata y fluida a las interacciones del usuario.

### 🛠️ Tecnologías utilizadas:
* HTML5 (Estructura funcional y accesible).
* CSS3 (Estilos modernos, animaciones suaves y adaptabilidad responsiva).
* JavaScript puro (Lógica de dinamismo y gestión de estados).
